# 《言霊の旅》自主學習成果發表簡報

15 頁、約 10 分鐘的高中自主學習成果發表簡報。每頁一個主題，畫面只放重點和圖，詳細內容放在講稿裡。

## 檔案

- `index.html`：簡報本體，用瀏覽器（Chrome／Edge）直接開啟。
- `SPEAKER_SCRIPT_AND_NOTES.md`：逐頁講稿、時間配速、可能被問到的問題。
- `assets/`：簡報用到的圖片與 30 秒宣傳影片（`promo.mp4`）。整個資料夾複製到隨身碟就能用，播放簡報不需要網路。
- `assets/vendor/pptxgen.bundle.js`：PPTX 轉換工具（PptxGenJS 3.12.0，MIT 授權）。
- `make-embedded-images.js`：換了 `assets/` 裡的圖片後執行 `node make-embedded-images.js`，更新匯出 PPTX 用的內嵌圖片。

## 操作

| 按鍵 | 功能 |
|:-:|---|
| `→`／`空白鍵`／點畫面右側 | 下一頁 |
| `←`／點畫面左側 | 上一頁 |
| `F` | 全螢幕 |
| `N` | 顯示這一頁的講稿與計時（只建議在自己的螢幕上用） |
| `E` | 開關編輯模式 |
| `Home`／`End` | 第一頁／最後一頁 |

把滑鼠移到畫面最上方，會出現工具列：**編輯文字・還原原始內容・下載 PPTX・講稿・全螢幕**。

## 編輯

- 按「編輯文字」（或 `E`）後，所有文字都可以直接點擊修改；下方講稿也能一起改。改完再按一次「完成編輯」。
- 修改會自動存在這台電腦的瀏覽器裡，重新開啟也還在。換電腦或換瀏覽器就要重新改，或改用匯出的 PPTX。
- 想回到原本的內容：按「還原原始內容」（封面的姓名欄位不受影響）。
- 封面的班級、座號、姓名、指導老師、發表日期隨時都能直接點擊修改。
- 發表人資料的預設值放在 `presenter.local.js`，這個檔案**不會提交進 git**（repo 是公開的），複製整個資料夾到隨身碟時會一起帶走。沒有這個檔案時封面會顯示空白欄位，可以照下面的格式自己建立：

  ```js
  window.PRESENTER_DEFAULTS = { class: '班級', seat: '座號', name: '姓名', advisor: '指導老師', date: '發表日期' };
  ```

## 轉成 PowerPoint

- 按「下載 PPTX」會產生 `言霊の旅_成果發表.pptx`：每一頁的文字都是可以編輯的文字方塊，色塊和圖片也都拆開，講稿放在每頁的「備忘稿」裡。你在網頁上改過的文字也會一起帶進去。
- 轉換工具已放在 `assets/vendor/`，沒有網路也能匯出 PPTX。
- 第 3 頁的影片在 PPTX 裡是一張封面圖；需要的話在 PowerPoint 用「插入 ▸ 視訊」把 `assets/promo.mp4` 放上去。
- PowerPoint 裡用的是「微軟正黑體」，字距和網頁版會有一點差異。

## 其他

- 第 3 頁的影片會在換到那一頁時自動播放，離開時暫停。
- 需要 PDF：`Ctrl + P` → 另存為 PDF（橫向）；或匯出 PPTX 後再用 PowerPoint 另存 PDF。
