# 言霊の旅（ことだまのたび）

> 用正確的日文，擊退吞噬語言的魔物。

一款在瀏覽器中執行的 **16-bit 像素風日文學習 JRPG**。答對日文題目就能攻擊魔物，透過探索、對話與首領戰，循序練習 **JLPT N4～N1** 的詞彙、助詞、動詞活用、語序與敬語。

**▶ 立即遊玩：<https://hinayoumiya-0721.github.io/kotodama-no-tabi/>**

不需要安裝、不用註冊，電腦和手機的瀏覽器都能玩，進度會自動存在瀏覽器裡。

---

## 特色

### ⚔️ 答題即戰鬥
- 720 題 JLPT N4～N1 題庫：單字讀音、助詞填空、動詞活用、句子重組、不自然表達辨析。
- **固定答題數**：每場戰鬥至少要答對 3 題（精英 4 題、首領 6 題）。裝備再強也不會減少練習量；連擊、速答、FEVER 能讓你打得更快。
- **自適應難度**：連續答對會自動往更高級的題目挑戰，答錯則會降回較簡單的難度。
- 首領戰分為三個階段，題型會隨首領剩餘血量改變。

### 🧭 探索與任務
- 6 個區域，從「始まりの町」一路到「言霊の聖域」。
- 每一步都要選路線：**安全小路**（前進慢、資源多）或 **危險捷徑**（前進快、多遇敵、獎勵 ×1.3）。
- 探索到一半會有**精英怪攔路**，探索度達到 100% 後首領才會現身。
- 任務卡有「**前往**」按鈕，可以直接跳到要去的地方；畫面上方隨時會顯示目前的主線目標。

### 🧠 為學習而設計
- **錯題筆記＋SRS 遺忘曲線**：答錯的題目會自動收錄，依 +1、+3、+7 天排程複習，連續答對 4 次即完全掌握。
- **答錯解析**：預設只顯示正解與一句重點，想深入了解再展開完整解析。
- **三段沉浸模式**：標準（假名＋中文）→ 進階（無假名）→ 全日文；任何時候都可以「偷看中譯」。
- 題目與對話都有**日文語音朗讀**，可切換一般與慢速。
- 閱讀副本（長文測驗）、試煉神殿（限時綜合測驗）、每日特訓。

### 🎨 16-bit 像素風
- 主角、城鎮居民與 18 隻怪物都是手繪像素立繪。
- 統一的 16×16 像素圖示，不同裝置看起來都一樣。
- 城鎮 NPC 有好感度與 AVG 式對話，可以練習在不同場合使用敬語。

## 操作說明

1. 在標題畫面選「踏上新旅途」，取名並選擇職業（言靈劍士／古籍學者／音韻旅藝人）與難度。
2. 先在**城鎮**和居民對話，再從底部選單的「**冒險**」進入世界地圖，選擇區域開始探索。
3. 戰鬥中選出正確答案即可攻擊；答得又快又準可以觸發破防和 FEVER。
4. 在「**修練**」的錯題筆記複習到期的錯題，在「**旅人**」整理裝備、學習技能。
5. 存檔視窗可以匯出存檔碼，換電腦或手機時再匯入即可繼續遊玩。

建議開啟音效，體驗日文語音朗讀。

## 在本機執行

這是純前端專案（HTML、CSS、JavaScript），不需要建置流程，也不用安裝任何套件（字型由 Google Fonts 線上載入）。

```bash
git clone https://github.com/hinayoumiya-0721/kotodama-no-tabi.git
cd kotodama-no-tabi
npx serve .        # 或任何靜態檔案伺服器，例如 python -m http.server
```

接著用瀏覽器開啟伺服器顯示的網址。建議透過本機伺服器開啟，不要直接雙擊 `index.html`。

### 測試

```bash
node tests/save-and-srs.test.js
```

共 26 項測試，涵蓋存檔匯入防護、SRS 規則、任務目的地與朗讀防洩題。只需要 Node.js，不用安裝其他套件。

### 重新產生像素圖示

圖示的原始定義在 `tools/gen-pixel-icons.js`（每個圖示是一張 16×16 的字元格子）。修改後執行：

```bash
node tools/gen-pixel-icons.js
```

輸出會寫到 `assets/icons/`，同時產生預覽頁 `assets/icons/preview.html`。

## 專案結構

```
index.html            主頁面
game.js               遊戲邏輯（戰鬥、探索、任務、SRS、存檔）
data.js               題庫、區域、敵人、道具、NPC 等資料
style.css             基礎版面與響應式排版
pixel-theme.css       16-bit 像素風主題（載入在 style.css 之後）
audio.js              Web Audio 音效與語音朗讀
svg_art.js            向量備援圖（沒有手繪圖時使用）
assets/portraits/     主角與城鎮居民立繪
assets/monsters/      怪物立繪與生圖提示詞（PROMPTS.md）
assets/icons/         像素 UI 圖示
tools/                圖示產生器
tests/                自動化測試
CHANGELOG.md          更新日誌
```
